# Rule source licenses

Each `.txt` file is copied from the exact upstream revision recorded in [release-manifest.json](../release-manifest.json). Generated rules retain upstream authorship and licensing. Metadata adaptations and original values are recorded in `provenance/<source>.json`; source YAML is available from the repository and commit SHA in the manifest.

The MIT declaration for the generator does not replace these rule licenses.

`rules_windows_all.json` combines Windows detections from the published sources and retains their authorship. Its contributing source revisions, licenses, and input hashes are listed in `provenance/windows_all.json`; the per-source license texts also apply to that combined file.
